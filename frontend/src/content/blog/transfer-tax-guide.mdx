매도 상담은 "양도세 얼마예요?" 한 마디로 시작합니다. 입력값이 13개라 손계산은 위험합니다.
법제처·국세청·홈택스·KB금융 등 **9 권위 출처를 교차검증**한 표준 산식으로 본세를 즉시 보여드립니다.

오늘 [/tools/transfer-tax](/tools/transfer-tax) 가 출시됐습니다 (2026-05-03). 1세대1주택 비과세,

## 핵심 함정 3가지

손님 앞에서 1분 안에 결과가 나오도록 설계했지만, 입력 단계에서 자주 놓치는 함정 셋만
미리 알고 들어가시면 좋습니다.

- **금액은 만원 단위**입니다. 15억 = `150000`, 5억 = `50000`. 원 단위로 잘못 적으면
  결과가 1억 분의 1로 떨어져 버리니 화면 안내를 꼭 보세요.
- **보유연수는 자동 계산**됩니다. 취득일·양도일을 ISO 형식으로 입력하시면 라이브러리가
  365.25일 기준으로 산출합니다. 사용자가 "보유 5년" 직접 입력 X — 날짜만 정확히.
- **한시배제 2026-05-09 종료** (D-Day 경과). 다주택 중과·장특공 배제는
  **2026-05-09 양도분까지**만 적용. 2026-05-10 이후 양도분은 +20%/+30%p 중과 부과.

## 사용 흐름 (3단계)

1. **가액 3개 입력** — 양도가액 / 취득가액 / 필요경비 (만원 단위)
2. **일자·거주연수 입력** — 취득일 / 양도일 / 거주연수 (1세대1주택 비과세 자격 판정)
3. **주택수·조정지역 선택** — 1·2·3주택 라디오 + 조정지역 체크박스 → 결과 즉시 표시

## 분기 6종 한 눈에

| 분기 | 조건 | 결과 |
|---|---|---|
| **empty** | 양도가액·취득가액 미입력 | 입력값 부족 안내 |
| **loss** | 양도가액 ≤ 취득가액+경비 | 양도차손, 산출세액 0원 |
| **unregistered** | 미등기 양도 체크 | 70% 단일세율 (장특공·기본공제 모두 배제) |
| **single-house-exempt** | 1주택 + 12억 이하 + 보유 2년+ + 거주 2년+ (조정 취득시) | 비과세, 산출세액 0원 |
| **single-house-prorate** | 1주택 + 12억 초과 + 위 조건 충족 | 12억 초과분 안분 + 표2 장특공 (최대 80%) |
| **general** | 위에 해당 안 되는 모든 경우 | 일반 누진세율 (단기/중과 시 장특공 미적용) |
