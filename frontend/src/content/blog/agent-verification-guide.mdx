사이트 가입은 끝났는데 사이트 사용은 어딘가 망설여지는 순간. 매물 메모를 남기려고
해도 "내 정보가 제대로 들어가 있나" 싶고, 손님께 "전문가가 운영하는 사이트"라는
인상을 드리고 싶지만 아직 일반 회원이라 보입니다. **이 5분 인증 한 번**으로
공인중개사 자격을 박제하고, 전문가 뱃지 + 고급 기능 잠금 해제 + 7일 무료 체험
정합성을 한 번에 확보합니다.

[/signup](/signup) → [/verify](/verify) → 사업자등록 자동 검증 → 자격증 서류 업로드
→ 즉시 또는 관리자 심사 후 [/pricing](/pricing) 7일 무료 체험. 절차는 단순하지만,
**상태 4 분기 (대기·승인·거부·자동승인)** 가 어떻게 갈리는지 미리 알면 신청 시
당황할 일이 없어집니다.

## 왜 인증을 받아야 하나

[2u.pe.kr](/)는 비즈니스 모델이 **공인중개사 B2B 구독**입니다 (블로그 글마다
[/pricing](/pricing) 박제). 일반 회원도 단지 검색·매물 조회·계산기는 모두 무료로
쓰실 수 있어요. 다만 **인증을 받으셔야만 이 3 가지 가치**가 잠금 해제됩니다.

**1. 손님께 신뢰 시그널** — 사이트 헤더에 **"전문가" 뱃지 (초록색)** 가 붙습니다.
손님 앞에서 "공인중개사 자격으로 운영하는 도구"라고 말씀드릴 수 있는 가시적
근거입니다. 일반 회원 vs 전문가 회원 차이를 손님이 직접 확인할 수 있어요.

**2. 7일 무료 체험 정합성** — [/pricing](/pricing) 7일 무료 체험은 **인증된
공인중개사 한정**입니다. 사이트 입장에서 일반 사용자에게 무료 체험을 풀면 구독
funnel 자체가 무너지기 때문에, 인증이 7일 체험의 진입권이에요.

**3. 고급 기능 접근** — 매물 메모/즐겨찾기 자동 동기화·관리자 카드 (Header
관리자 메뉴)·고급 분석 도구 (시세 추이 다중 비교 등)가 인증 회원에게만 노출됩니다.
일반 회원은 매물 메모를 브라우저 localStorage 단일 기기에서만 쓸 수 있고,
인증 후에는 향후 서버 동기화 옵션이 추가됩니다 ([/pricing](/pricing) 로드맵).

## 절차 1단계 — 사업자등록번호 자동 검증

[/verify](/verify) 페이지에 들어가면 **사업자등록번호 (10자리)** + **대표자명** 두
필드가 필수입니다. 사업자등록번호는 `000-00-00000` 형식 (하이픈 자동 정리), 대표자명은
한글·영문 모두 가능합니다.

> **"사업자 정보를 입력하면 자동 검증을 진행합니다. 자격증 서류를 첨부하면 관리자가
> 확인합니다."**

사업자등록번호 입력 후 "인증 신청" 버튼을 누르면 사이트가 백엔드에서 자동으로
번호를 검증합니다. **자동 검증 성공 시 곧바로 `auto_approved` 분기**로 넘어가
전문가(Expert) 권한이 즉시 부여돼요. 별도 심사 없이 헤더 뱃지가 바로 초록색으로
바뀝니다.

자동 검증 실패 시 (등록번호 형식 오류·해지된 사업자 등) 안내 메시지가 노란색으로
노출됩니다. 이 경우 다음 단계(자격증 업로드)로 넘어가면 관리자 심사 대기열에
들어갑니다.

## 절차 2단계 — 공인중개사 자격증 업로드 (선택)

자격증 서류는 **선택 항목**입니다. 사업자등록번호 자동 검증만으로 `auto_approved`
가 떨어지면 자격증 없이도 인증이 완료되지만, 자동 검증이 실패했거나 더 강한 신뢰
시그널을 원하실 때 자격증을 첨부해 관리자 심사를 받습니다.

업로드 형식은 **JPG · PNG · PDF** 3 종, 한 파일당 **최대 5MB**. 점선 박스 안을
**클릭하거나 파일을 드래그 앤 드롭**으로 첨부할 수 있습니다. 폼 검증이 자동으로
형식·크기를 확인해 잘못된 파일이면 빨간색 안내가 뜨니, 문제 발견 즉시 다른 파일을
시도하시면 됩니다.

자격증 파일이 첨부되면 1단계 자동 검증과 함께 백엔드로 전송됩니다. 관리자가
파일을 확인한 뒤 승인 또는 거부 결정을 내리는 수동 분기예요.

## 절차 3단계 — 중개사무소명 (선택)

마지막으로 **중개사무소명** 필드는 선택 입력입니다. 입력하시면 손님께 노출되는
프로필 영역에 사무소명이 함께 표시되어 추가 신뢰 시그널이 됩니다 (예: "○○공인중개사
사무소"). 입력 안 하셔도 인증 결과에는 영향 없어요.

세 필드 모두 입력 후 **"인증 신청"** 버튼 한 번이면 끝입니다. 백엔드는 자동
검증 → 자격증 업로드 (있을 때) → 결과 분기 순서로 처리하고, 즉시 결과 화면을
보여드립니다.

## 상태 4 분기 — 무엇이 다른가

신청 후 화면이 어떤 상태로 보이는지 **4 분기**로 정리했습니다.

**1. `auto_approved` (자동 승인 ✅)** — 사업자등록번호 자동 검증 성공. **그 자리에서
전문가 권한 부여**, 헤더 뱃지 초록색, [/pricing](/pricing) 7일 무료 체험 즉시 가능.

**2. `pending` (심사 대기 ⏳)** — 자격증 서류 업로드 후 관리자 심사 대기 중.
노란색 뱃지로 "심사 대기 중"이 노출되고, 결과는 사이트 알림으로 안내드립니다.
보통 영업일 기준 1~2일 안에 결정됩니다.

**3. `approved` (수동 승인 ✅)** — 관리자가 자격증을 확인 후 승인. **전문가 권한
부여**, 헤더 뱃지 초록색, "홈으로 이동" 링크 노출. 이후 동작은 `auto_approved` 와
동일합니다.

**4. `rejected` (거부 ❌)** — 관리자 심사에서 거부. 빨간색 뱃지로 "거부됨"이
노출되고, **거부 사유가 본문에 공개**됩니다 (예: "자격증 사본이 너무 흐려 식별
불가"). "재신청하기" 버튼이 함께 노출되어 다른 자격증 파일을 첨부해 다시 신청할
수 있어요.

## 인증 후 변화 — 일반 회원 vs 전문가

인증 전후 사이트 사용 차이를 한눈에 정리하면 이렇습니다.

| 항목 | 일반 회원 | 전문가 회원 |
|---|---|---|
| Header 뱃지 | 없음 | 초록 "전문가" |
| /pricing 7일 무료 체험 | 차단 | 즉시 가입 |
| 매물 메모/즐겨찾기 | 단일 기기 localStorage | 향후 서버 동기화 |
| /admin 카드 | 비공개 | 공개 (구독 시) |
| 고급 분석 도구 | 비공개 | 공개 |

손님 앞에서 "전문가" 뱃지가 보이는 것 자체가 **무료로 얻는 마케팅 자산**입니다.
인증 5분에 비하면 가성비가 좋아요.

## 자주 막히는 지점 — 6 시나리오

신청 흐름에서 손님분들이 가끔 막히는 6 시나리오를 정리했습니다.

**1. 사업자등록번호 형식 오류** — `000-00-00000` 형식만 자동 인식됩니다. 하이픈은
자동으로 제거되어 검증되지만, 자릿수 오류면 빨간색 알림이 떠요.

**2. 대표자명 빈 값** — `*` 표시 필수 항목입니다. 사업자등록증에 적힌 대표자명과
**정확히 일치**해야 자동 검증을 통과합니다.

**3. 자격증 파일 5MB 초과** — 모바일 카메라로 찍은 원본 사진은 종종 5MB 를
넘습니다. 사진 앱에서 "공유 → 메일 보내기 → 작은 크기"로 압축한 뒤 다운로드해
업로드하시면 안전합니다.

**4. JPG/PNG/PDF 외 형식** — HEIC (아이폰 기본 형식)·WebP 는 차단됩니다. 사진
앱에서 JPG 로 변환 후 업로드하세요.

**5. 자동 검증 실패 후 재시도** — 자동 검증이 실패해도 자격증 업로드 후 관리자
심사를 거치면 됩니다. 실패라고 포기하지 마시고 자격증 파일과 함께 신청하세요.

**6. 거부 후 재신청** — 거부 화면의 "재신청하기" 버튼을 누르면 폼이 다시 열립니다.
거부 사유를 보고 자격증 파일을 다른 것으로 바꿔 첨부하시면 다시 심사 대기열로
들어갑니다.
