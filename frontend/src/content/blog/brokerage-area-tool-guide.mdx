중개수수료와 면적 변환은 공인중개사가 가장 자주 손에 쥐는 두 계산입니다. 계약서를 쓰기
전에 수수료를 정확히 안내해야 하고, 손님이 "전용 84㎡가 몇 평이에요?"라고 물으면 1초 안에
답해야 합니다. 이 글은 [중개수수료 계산기](/tools/brokerage-fee)와
[면적 변환 계산기](/tools/area-converter) 두 도구의 사용 흐름을 손님 응대 시나리오별로
정리합니다.

다른 세금 계산기(취득세·양도세·보유세)는 입력값이 많고 분기가 복잡해 글이 따로 있지만,
이 두 도구는 화면이 단순합니다. 그만큼 **함정을 미리 알고 들어가는 것**이 중요합니다.

## 1. 중개수수료 계산기 — 4종 거래유형 자동 요율

[/tools/brokerage-fee](/tools/brokerage-fee)는 국토교통부 공인중개사법 시행규칙 별표1을
기준으로 요율을 자동 적용합니다. 입력은 세 묶음으로 끝납니다.

### 거래유형 (4종)

- **매매·교환** — 주택 매매 6구간 누진 요율
- **전세 (임대차)** — 주택 임대 6구간 누진 요율
- **월세** — 환산보증금으로 변환 후 임대 요율 적용
- **토지·상가 등** — 0.9% 이하 협의형

### 매물유형 (3종)

- **주택** — 별표1 주택 요율표
- **오피스텔 (주거용)** — 전용 85㎡ 이하 + 입식부엌·수세식·세면대를 모두 갖춘 경우.
  매매 0.5%·임대 0.4% 고정 요율
- **오피스텔 (그 외)** — 0.9% 이하 협의형

### 부가세 (2종)

- **일반과세** — 수수료에 10% 부가
- **간이과세** — 부가세 면제

## 사용 흐름 (3단계)

화면이 단순해 손님 앞에서 30초면 끝납니다.

1. **거래유형·매물유형 선택** — 라디오 버튼을 차례로 클릭합니다. 거래유형을 바꾸면 금액
   입력값이 0으로 초기화되니, 유형부터 정하고 금액을 넣으세요.
2. **금액 입력** — 매매·전세면 거래금액 한 칸, 월세면 보증금과 월세 두 칸. **모두 만원
   단위**입니다. 5억은 `50000`, 12억은 `120000`. 원 단위로 적으면 요율이 엉뚱하게
   떨어지니 입력 칸 아래 안내를 꼭 확인하세요.
3. **결과 확인** — 적용 요율, 한도액, 수수료(부가세 포함·미포함)가 카드로 즉시 표시됩니다.

## 핵심 함정 세 가지

- **월세는 환산보증금으로 계산** — 공식은 `보증금 + (월세 × 100)`. 환산보증금이 5천만원
  미만이면 `보증금 + (월세 × 70)`을 다시 적용합니다(시행규칙 단서). 계산기가 이 분기를
  자동 처리하므로 보증금과 월세만 정확히 넣으면 됩니다.
- **오피스텔 주거용 판정** — 전용 85㎡ 이하이면서 입식부엌·수세식 화장실·세면대를 모두
  갖춰야 "주거용" 0.5%·0.4% 고정 요율입니다. 하나라도 빠지면 "그 외"로 분류돼 0.9%
  협의형이 됩니다.
- **토지·상가 협의형은 상한값** — 0.9%는 법정 상한이지 확정 요율이 아닙니다. 계산기는
  상한 기준 금액을 보여주고, 손님과 협의한 실제 요율은 별도 안내하시면 됩니다.

## 2. 면적 변환 계산기 — 평과 ㎡ 양방향

[/tools/area-converter](/tools/area-converter)는 **1평 = 3.3058㎡** 표준 환산을
양방향으로 계산합니다. 한쪽 칸에 숫자를 넣으면 반대쪽이 자동으로 채워집니다.

- **㎡ → 평** — 입력값 ÷ 3.3058, 소수점 1자리로 표시
- **평 → ㎡** — 입력값 × 3.3058, 정수로 표시

네이버 부동산 표기와 같은 소수점 자리로 맞췄기 때문에, 손님에게 보여주는 숫자가 매물
정보와 어긋나지 않습니다.

### 퀵 버튼으로 더 빠르게

자주 쓰는 면적은 버튼 한 번으로 입력됩니다.

- **㎡ 쪽** — 59㎡ · 84㎡ · 114㎡ · 135㎡ (국민주택 대표 평형)
- **평 쪽** — 18평 · 25평 · 34평 · 41평

손님이 "25평이면 몇 ㎡예요?"라고 물으면 평 쪽 `25평` 버튼만 누르면 됩니다.

## 손님 응대 시나리오

두 도구는 따로 쓰기보다 **한 흐름에서 이어 쓰는 경우**가 많습니다.

- **매매 상담** — 면적 변환으로 "전용 84㎡ = 약 25.4평"을 먼저 확인시켜 손님이 매물
  크기를 감 잡게 한 뒤, 중개수수료 계산기로 "이 금액대면 수수료가 얼마"인지 바로
  안내합니다.
- **월세 상담** — 보증금·월세를 그대로 넣으면 환산보증금 분기가 자동 적용돼, 손님이
  "월세인데 수수료가 왜 이렇게 나와요?"라고 물을 때 환산 공식을 화면으로 설명할 수
  있습니다.
- **오피스텔 상담** — 주거용·비주거용 요율 차이가 크므로, 매물유형 라디오를 바꿔가며
  두 경우를 모두 보여주면 손님이 판단하기 쉽습니다.
