# 한국어 도메인 용어집 (부동산 세금·매물)

세션 109 (2026-05-05) 신설. Claude가 코드 작성·Notice 본문·블로그 mdx 작성 시 도메인 용어 정확 표기에 활용.

> **사용법**: 새 용어 박제 시 본 파일에 한 줄 추가. ASSETS.md §1 PDF 매핑과 §2 NoticeKey가 권위 출처 트레이스. 본 파일은 **정의 사전**, ASSETS.md 는 **자산 인덱스**.

---

## §1 가격·시세 기준

| 용어 | 영문 키 | 정의 | 권위 출처 |
|---|---|---|---|
| **공시가** | publishedPrice | 정부가 매년 발표하는 부동산 평가액. 보유세(재산세·종부세) 과세표준의 기준값. 시세보다 보통 60~80% 수준. | ASSETS.md §1 PDF #2·#3 |
| **시세** | marketPrice | 실제 거래 가격. 양도세 양도가액·중개수수료 기준. 본 계산기는 시세 입력 안 받음. | (시세 미사용) |
| **공정시장가액비율** | fairMarketRatio | 공시가에 곱해 과세표준을 만드는 비율. 종부세는 60% 단일 / 재산세는 1세대1주택 43~45% 차등 (세션 108 PDF 재검수 정정, 본 계산기는 60% 일괄). | ASSETS.md §1 PDF #3 (L1 흐름도) |
| **평·㎡ 변환** | M2_TO_PYEONG | 1평 = 3.3058㎡. `frontend/src/lib/constants.ts` `convertArea` (L9). | (수학식, 세션 82) |

## §2 세금 종류

| 용어 | 영문 키 | 정의 | 출시 도구 |
|---|---|---|---|
| **종합부동산세** (종부세) | comprehensiveTax | 보유 주택 합산 공시가가 일정 기준 초과 시 부과 (1세대1주택 12억 / 일반 9억). 누진세율 7구간. | `/tools/property-tax` (보유세) |
| **재산세** | propertyTax | 매년 7월·9월 부과. 지방세, 4구간 누진. 1세대1주택 특례 세율 (§111의2) 별도. | `/tools/property-tax` (보유세) |
| **양도소득세** (양도세) | transferTax | 부동산 매도 시 양도차익에 부과. 누진/단기/중과 분기 + 1세대1주택 비과세. | `/tools/transfer-tax` |
| **취득세** | acquisitionTax | 부동산 취득 시 부과 (1~12% 차등). 지방세, 주택·오피스텔·법인 분기. | `/tools/acquisition-tax` |
| **중개수수료** | brokerageFee | 공인중개사 수수료. 거래유형(매매/임대)·금액 구간별 요율 차등. | `/tools/brokerage-fee` |

## §3 1세대1주택 관련 (보유세 핵심)

| 용어 | 영문 키 | 정의 | 권위 출처 |
|---|---|---|---|
| **1세대1주택자** | singleHouse | 세대 전체가 1주택 보유. 종부세 12억 공제 + 연령·보유 세액공제 최대 80%. 자격 까다롬 (세대원 무주택 등). | ASSETS.md §1 PDF #16 |
| **합산배제** | exclusion | 임대주택·사원용주택·주택신축용토지 등 일정 요건 충족 시 종부세 합산에서 제외. 매년 9.16~9.30 신청. | ASSETS.md §1 PDF #8·#9·#10 |
| **공동명의** | jointOwnership | 부부·가족 공동 소유. 종부세는 인별 과세라 각자 9억 공제. 단, 부부 공동명의 1주택자 특례 신청 시 1인 합산 12억 + 세액공제 80%. | ASSETS.md §1 PDF #11 |
| **부부 공동명의 1주택자 특례** | spouseJointSingleHouse | 부부 공동소유 1주택일 때 특례 신청 시 1인 합산 납세 → 12억 공제 + 세액공제 80%. 매년 9.16~9.30 별지 제30호 서식. (세션 108 출시 B-5) | ASSETS.md §1 PDF #11 |

## §4 세율·공제 산식

| 용어 | 영문 키 | 정의 | 위치 |
|---|---|---|---|
| **누진공제** | progressiveDeduction | 누진세율 적용 시 구간별 누적 공제액. (세표 × 세율 - 누진공제) 산식. | property-tax-brackets.ts / transfer-tax-branches.ts |
| **단일세율** | flatRate | 누진 아닌 단일 세율. 법인 보유 주택은 2주택 이하 2.7% / 3주택 이상 5.0%. | ASSETS.md §1 PDF #14 |
| **세부담 상한 (cap)** | taxBurdenCap | 지방세법 §122 — 전년 대비 보유세 150% 초과분은 자동 캡. 본 도구는 전년도 보유세 입력 시 자동 적용. | ASSETS.md §1 PDF #1 §122 |
| **세액공제** | taxCredit | 산출세액에서 차감. 1세대1주택 종부세는 연령(60세 20%·65세 30%·70세 40%) + 보유(5년 20%·10년 40%·15년 50%) 합산 최대 80%. | ASSETS.md §1 PDF #2·#16 |
| **농어촌특별세** | ruralTax | 종부세액의 20% 별도 부과. 법인은 차단. | ASSETS.md §1 PDF #2 |

| **단기 중과 (1년·2년)** | shortTermSurcharge | 1년 미만 70% / 2년 미만 60% 단일세율. 누진보다 우선. | ASSETS.md §1 PDF (없음, 법제처 §95②) |

| **한시배제** | exemptionGrace | 정부 한시 조치로 다주택 중과 일정 기간 적용 배제. 본 계산기 EXEMPTION_END_DATE 코드 상수 (세션 102 routine 알람). | transfer-tax-branches.ts |
| **양도차손** | transferLoss | 양도가액 < (취득가액 + 필요경비). 양도세 0. | transfer-tax-types.ts loss-no-tax |

## §8 본 용어집 갱신 관행

1. 코드/Notice/mdx에 새 한국어 용어 박제 시 → 본 파일에 한 줄 추가
2. 권위 출처는 ASSETS.md §1 PDF 번호로 트레이스 (한국어 PDF 파일명 직접 인용 금지)
3. 영문 키는 코드 NoticeKey 또는 산식 변수명과 일치
4. drift 의심 시: `git log --oneline -- .claude/GLOSSARY.md` 로 최근 갱신 확인
