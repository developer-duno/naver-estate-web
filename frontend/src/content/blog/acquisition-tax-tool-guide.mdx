"이 집 사면 취득세 얼마예요?" — 손님이 물어본 순간, 머릿속으로 매매가 × 1%
곱하다가 "농특세 + 교육세까지 합치면…" 흘려본 적 있으시죠. **이 30초를
즉답 30초로 바꾸는 도구**가 [/tools/acquisition-tax](/tools/acquisition-tax)
취득세 계산기입니다.

매물유형 + 매매가 + 면적 + 보유주택수 + 조정 + 생애최초 6개 토글. 끝입니다.
표준세율·다주택 중과·생애최초 200만 감면·오피스텔 4% **5 분기** 자동 판정. 손님
앞에서 화면 같이 보면서 "본세 ○○○만원, 농특세·교육세 합쳐 ○○○만원입니다" 즉답
가능합니다.

## 5 분기 자동 판정 — 손님 시나리오 별 한 줄 답

도구 내부는 손님이 입력한 6개 토글에 따라 자동으로 5 분기 중 하나로 빠집니다.

| 분기 | 적용 조건 | 본세율 |
|---|---|---|
| **standard** (표준) | 1주택 매매 | 1%(~6억) → 보간(6~9억) → 3%(9억+) |
| **multi-house** (다주택 중과) | 2주택 조정=8% / 3주택 조정=12%·비조정=8% | 8% 또는 12% |
| **first-time** (생애최초 감면) | 무주택 1주택 ≤12억 | 표준세율 + 본세 200만 한도 감면 |
| **officetel** (오피스텔·상가) | 매물유형 = 오피스텔 | 4% 고정 |
| **first-time-rejected** (생애최초 거부) | 무주택 + 12억 초과 | 표준세율 + 거부 사유 안내 |

손님 응대 시 "1주택이면 1%, 다주택 조정이면 8%, 오피스텔은 4% 고정입니다" 같은
비교가 1초 안에 가능합니다.

## 6억·9억 보간 구간 — 표준세율의 함정

표준세율은 가격 구간별로 다릅니다.

- **6억 미만**: 1% 고정
- **6~9억 사이**: 선형 보간 — `(매매가 × 2 / 3억 - 3) ÷ 100`
- **9억 초과**: 3% 고정

7억 1주택 84m² 시나리오를 예로 들면, 보간 공식 적용 시 **1.667%** → 본세
**1166만원**이 나옵니다. "8억은 2%, 7억은 1.67%" 같은 구간별 차이를 손님께
즉답할 수 있어요.

도구는 입력한 매매가가 6~9억 범위에 들어가면 자동으로 보간을 적용하므로,
별도로 구간을 외울 필요 없습니다.

## 전용 85m² 비밀 — 농특세 0원 조건

농어촌특별세는 분기별로 세율이 다른데, **전용면적 85m² 이하 + 1주택**일 때만
0원이 됩니다.

| 조건 | 농특세율 |
|---|---|
| **1주택 + 85m² 이하** | **0%** (비과세) |
| **1주택 + 85m² 초과** | 0.2% |
| **다주택 + 8% 중과** | 0.6% (면적 무관) |
| **다주택 + 12% 중과** | 1.0% (면적 무관) |
| **오피스텔** | 0.2% (면적 무관) |

5억 1주택 84m² 시나리오면 농특세 0원 → 본세 500만 + 교육세 50만 = **합계
550만원**입니다. 같은 5억이라도 110m² 이상이면 농특세 100만원이 추가돼
**650만원**으로 올라가요. 손님께 "전용 85m² 라인이 농특세 갈림길입니다"
한 줄 답이 가능합니다.

## 생애최초 200만원 감면 — 본세만, 농특·교육세는 표준

무주택 손님이 첫 집을 사실 때 적용 가능한 분기입니다.

**자격**:
- 생애 최초로 주택을 매수하는 무주택 세대
- 매매가 12억 이하

**감면 효과**:
- 본세에서 **200만원 한도** 차감
- 농특세·교육세는 표준 그대로 (감면 무관)

5억 시나리오면 본세 500만 → 200만 감면 → 300만. 농특 0 + 교육 50만 = **합계
350만원**으로 떨어집니다. 표준 550만 대비 200만원 절약이에요.

**비활성 우선순위** (도구 안에서 자동 판정):

1. 매물유형이 오피스텔 → 생애최초 토글 비활성
2. 매매가 12억 초과 → 생애최초 토글 비활성 + first-time-rejected 분기 진입
3. 보유주택수 2주택 이상 → 생애최초 토글 비활성

12억 초과 거부 케이스는 표준세율로 그대로 계산되지만, 결과 카드에 **"생애최초
적용 불가 — 12억 초과"** 사유가 안내됩니다. 손님이 "왜 감면 안 되나요?"
물어보실 때 화면 그대로 보여드리시면 됩니다.

## 손님 응대 화법 예시

표·아이콘만 봐서는 "이 도구를 손님 앞에서 어떻게 꺼내야 하나" 막막할 수
있습니다. 실제 사무실에서 쓰는 화법 3가지를 추천드립니다.

> "5억 1주택 84m² 매수면 본세 500만 + 농특세 0 + 교육세 50만 = 합계 550만원
> 입니다. 생애최초이시면 본세 200만 감면돼서 350만원으로 떨어져요. 화면에서
> 토글 켜드릴게요."

> "10억을 2주택 + 조정대상지역에서 매수면 본세 8000만 + 농특세 600만 + 교육세
> 400만 = 합계 9000만원입니다. 같은 10억이라도 1주택이면 3000만, 비조정이면
> 8000만. 화면에서 토글로 비교해 보실까요?"

> "7억 1주택 110m²면 6~9억 보간 구간이라 본세 1166만 + 농특세 140만 + 교육세
> 116만 = 합계 1422만원입니다. 8억으로 가면 본세 1600만으로 오르니, 같은
> 1주택도 가격대별 차이가 큽니다."

손님은 **"세무사 상담 받아보세요" 보다 "지금 화면 같이 보면서 계산해드릴게요"** 를
훨씬 신뢰합니다. 취득세 도구는 그 첫 번째 layer 가 됩니다.
