펼쳐도 손님 앞에서 한 줄 답이 안 나오는 영역입니다. 객관 비교는 가능하지만
"투자 우선이냐 실거주 우선이냐"가 들어오면 다시 머릿속 줄세우기. **이 30초를

앞에서 "78점, 이 단지가 당신 성향에 가장 맞습니다" 즉답 가능합니다.

## 9축 + 인프라 4축 = 13축 정량 비교

레이더 차트는 단지의 정량 지표를 13개 축으로 표준화해 한눈에 비교합니다.

**기본 9축** (단지 자체 정보):

| 축 | 의미 | 좋은 방향 |
|---|---|---|
| **세대수** | 단지 규모 | 클수록 |
| **세대당 주차** | 세대당 주차대수 | 높을수록 |
| **최고층** | 최고층수 | 높을수록 |
| **전세가율** | 전세가/매매가 | 높을수록 (임대 수요) |
| **주변시세** | 인근 단지 매매 중간값 | 높을수록 (주변 가치) |
| **할인율** | 분양가 대비 할인 폭 | 높을수록 (매수자 유리) |
| **미분양률** | 미분양/분양 세대 비율 | **낮을수록** (invert) |
| **평당가** | 분양가 / 평수 | **낮을수록** (invert) |
| **용적률** | 부지 활용도 | **낮을수록** (invert, 쾌적) |

**인프라 4축** (선택 활성, 손님 거주 환경 중시 시):

| 축 | 의미 | 데이터 출처 |
|---|---|---|
| **대기질** | 4 등급 (좋음/보통/나쁨/매우나쁨) | 에어코리아 API |
| **의료인프라** | 응급의료기관 수 | NEMC API |
| **보육** | 어린이집 수 | CPMS API |
| **치안** | 범죄통계 점수 | 경찰청 odcloud |

invert 표시된 3축(미분양률·평당가·용적률)은 **숫자가 낮을수록 차트에서 멀리
뻗어** 시각적으로 "좋은 단지" 모양이 한눈에 보이도록 설계됐습니다.

## 정규화 산식 — 0~100 표준화 비법

각 축은 단지마다 단위가 다르기 때문에 (세대 vs % vs 만원) 그대로 비교할 수
없습니다. 도구는 max 기준 비율로 0~100 점수로 표준화합니다.

- **비 invert 축**: `(raw / max) × 100` — max 단지가 100점, 다른 단지는 비율
- **invert 축**: `((max - raw) / max) × 100` — 최저 단지가 100점

예를 들어 3 단지 비교 시 세대수가 [500, 1000, 800] 이면 max=1000 이라 [50,
100, 80] 점으로 환산. 미분양률이 [10%, 5%, 20%] 면 invert 적용으로 [50, 75,
0] 점.

차트에서 "멀리 뻗은 모양" 이 좋은 단지라는 직관이 모든 축에 공통으로 적용돼,
손님이 13축 의미를 몰라도 모양만으로 1초에 우위 단지를 가려낼 수 있습니다.

## 프리셋 3종 — 손님 성향별 1초 줄세우기

레이더 아래에 **가중치 프리셋 3종** 버튼이 있습니다. 한 번 클릭하면 13축의
가중치가 일괄 적용되고 종합 점수가 즉시 재계산됩니다.

- **균등** (모두 3) — 객관 비교, 포트폴리오 다각화 손님
- **투자형** (전세가율·주변시세·할인율 5 + 미분양률·평당가 4) — 임대 수익·시세차익 손님
- **실거주형** (주차 5 + 의료 5 + 보육 5 + 세대수·용적률·치안·대기질 4) — 거주 쾌적성 손님

손님이 "임대 줄 거예요" 하시면 **투자형** 한 번 누르고 종합 점수만 보시면 답
나옵니다. "직접 살 거예요" 하시면 **실거주형** 으로 다시 누르고 점수가 어떻게
뒤집히는지 보여드리면 됩니다.

## 가중치 슬라이더 (1-5) — 손님 미세 조정

프리셋만으로 부족한 손님을 위해 13축 각각의 가중치를 1~5로 미세 조정할 수
있습니다.

- **details 접이식** (기본 닫힘) — "축별 가중치 조정 ▼" 클릭으로 펼침
- **활성 축만 표시** (반응형 grid-cols-1/sm-2/md-3) — 최소 3축은 항상 활성
- **1점** = 무시 / **3점** = 균등 / **5점** = 최우선
- **localStorage 영속화** (`mb_radar_settings` 키) — 다음 상담 진입 시 가중치 자동 복원

"이 손님은 주차가 가장 중요해" 라고 판단되시면 슬라이더에서 주차만 5로 올리고
나머지는 그대로 두시면, 종합 점수에서 주차 비중이 압도적으로 반영됩니다.
점수 1~2점 차이로도 우위 단지가 뒤바뀌니, 미세 조정의 가치가 큽니다.

## 종합 우위★ 산식 — 78점 한 줄 답

가중치 적용 후 종합 점수는 다음 산식으로 계산됩니다.

```
종합 점수 = Σ(정규화값 × 가중치) / Σ(가중치)
```

- 활성 축만 합산 (비활성 축 제외)
- 결과는 0~100 정수로 반올림
- 차트 아래 **"★ 종합 우위: ○○ 단지 (78점)"** 자동 표시

3 단지 비교에서 점수가 [72, 78, 65] 면 78점 단지가 종합 우위. 손님께 "이 손님
성향이면 ○○ 단지가 가장 좋습니다 (78점)" 한 줄 답 가능합니다. 점수 1점 차이도
우위 뒤바뀜이 잦으므로, 가중치를 손님 앞에서 미세 조정하면서 비교하시는 게
좋습니다.

## 손님 응대 화법 예시

13축 + 가중치 + 점수 시스템을 손님 앞에서 어떻게 꺼내야 하나 막막할 수
있습니다. 실제 사무실에서 쓰는 화법 3가지를 추천드립니다.

> "투자 목적이시죠? 투자형 프리셋 한 번 누르고 종합 점수 보세요. 78점 단지가
> 가장 임대수익 + 시세차익이 좋습니다. 전세가율·주변시세·할인율 가중치가 5라
> 이 세 축이 점수를 결정해요."

> "실거주 목적이시면 실거주형으로 바꿔볼게요. 점수가 뒤집히죠? 주차·의료·보육
> 우선이라 ○○ 단지가 더 좋습니다. 같은 단지라도 손님 성향에 따라 점수가
> 20~30점 차이 나요."

> "객관 비교로는 △△ 단지가 평균 점수 가장 높지만, 손님 우선순위 알려주시면
> 다시 줄세워드려요. 주차가 중요하시면 슬라이더에서 5로 올리고, 미분양률
> 신경쓰시면 그것도 5로. 점수 실시간 갱신됩니다."

손님은 **"4 단지 비교표만 펼쳐드려요" 보다 "손님 성향 알려주시면 1초에
줄세워드릴게요"** 를 훨씬 신뢰합니다. 미분양 레이더 가중치는 그 첫 번째
layer 가 됩니다.
