손님 앞에서 상담을 마무리할 때 "PDF 로 보내드려도 될까요" "엑셀 한 장 더 받을 수 있을까요"
요청은 자주 들어옵니다. 이때마다 자료를 다시 만들면 5분이 사라지죠. 이 사이트는 **엑셀 6곳 +
인쇄 1곳 = 총 7 위치**에서 손님 자료를 1분 안에 떨어뜨리도록 설계해 두었습니다.

엑셀은 4단지 비교 / 미분양 단지 목록 / 지역 통계 / 실거래 / 미분양 추이 / 미분양 비교 6개 화면에서
바로 다운로드되고, 인쇄는 단지 비교 화면(4단지)에서 한 장짜리 자료로 나옵니다. 이 글에서는
**각 위치 사용법 + 엑셀 계산식 악용 막기 + 파일을 브라우저가 만드나 2u 쪽이 만드나의 차이**를 한 줄씩 풀어둡니다.

## 엑셀 내보내기 6 위치 — 한 줄 정리

손님 자료 유형별로 어느 화면에서 어떤 파일이 떨어지는지 표로 정리했습니다. 파일명은 모두
한국어 + 날짜 형식이라 손님께 보내드릴 때 그대로 의미가 통합니다.

| 화면 | 버튼 위치 | 파일명 형식 | 칸 수 |
|---|---|---|---|
| 단지 비교 (4단지) | 상단 "엑셀 다운로드" | `단지비교_YYYY-MM-DD.xlsx` | 항목 + 단지 N |
| 단지 상세 매물 목록 | 상단 "엑셀 다운로드" | `{단지명}_{시각}.xlsx` | 28칸 |
| 미분양 단지 | 상단 "엑셀" | `미분양단지_YYYY-MM-DD.xlsx` | 11칸 |
| 미분양 지역 통계 | 탭 안 "엑셀" | `지역통계_YYYY-MM-DD.xlsx` | 10칸 |
| 미분양 실거래 | 탭 안 "엑셀" | `실거래_YYYY-MM-DD.xlsx` | 11칸 |
| 미분양 단지 상세 미분양 추이 | 차트 옆 "엑셀" | `미분양추이_{단지명}_YYYY-MM-DD.xlsx` | 4칸 |
| 미분양 비교 | 상단 "엑셀" | `미분양비교_YYYY-MM-DD.xlsx` | 항목 + 단지 N |

표를 세어 보시면 7행입니다. 매물 목록은 2u 쪽에서 만들어 보내는 1곳이고, 나머지 6곳은
브라우저에서 직접 파일을 만들어 다운로드합니다 (아래 "누가 파일을 만드나" 참고).

## 인쇄 1 위치 — 단지 비교 화면 한 장 자료

손님께 종이 자료를 드릴 때는 단지 비교 화면의 인쇄 버튼을 권합니다. 4단지 비교
24행 + 5종 차트가 한 장 (또는 두 장) A4 자료로 떨어져요. 다른 화면 인쇄는 브라우저 기본 인쇄
(Ctrl+P) 로 줄이 흐트러질 수 있어 권장하지 않습니다.

인쇄 버튼 한 번 누르면 내부에서 세 단계가 자동으로 돕니다.

1. **모든 행 펼침** — 24행 中 접혀 있던 비교 행을 한 번에 다 펼쳐서 인쇄 영역에 포함시킵니다.
2. **화면이 다 그려질 때까지 기다림** — 펼친 내용이 화면에 다 그려질 때까지
   두 번 기다립니다. 한 번만 기다리면 일부 행이 빈 상태로 인쇄될 수 있어요.
3. **인쇄 창 열기** — 컴퓨터의 인쇄 창이 뜹니다. PDF 로 저장하시려면 "PDF 로 저장"
   프린터를 고르시면 됩니다.

인쇄가 끝나면 펼쳤던 칸이 자동으로 원래대로 접힙니다. 손님께서
"한 번 더 인쇄해도 될까요" 하실 때 화면 상태가 인쇄 직전 그대로 남아 있지 않아 다음 단지 비교에
방해되지 않아요.

## 엑셀 계산식 악용 막기 — 엑셀로 손님 PC 가 공격당하지 않게

엑셀 파일을 외부에서 열 때 `=` `+` `-` `@` 같은 글자로 시작하는 칸이 있으면 **계산식으로 읽혀**서
의도치 않은 동작이 일어날 수 있어요. 단지명이 `=` 로 시작하는 나쁜 글자를 손님이 받아
열면 PC 가 위험해질 수 있습니다.

사이트는 엑셀 칸에 글자를 쓰기 전에 첫 글자만 확인합니다. **첫 글자가 `=` `+` `-` `@` 와 탭·줄바꿈 글자,
이 6개 中 하나면** 앞에 작은따옴표 `'` 를 자동으로 붙여서 보통 글자로 만들어 버립니다. 그러면
엑셀이 더 이상 계산식으로 읽지 않아요.

이 막기는 **브라우저가 만드는 엑셀 6곳 + 2u 쪽이 만드는 엑셀 1곳** 모두 같은 6글자 패턴으로 동일하게 들어가
있어요. 어느 화면에서 받은 파일이든 손님 PC 가 위험에 노출되지 않습니다.

## 누가 파일을 만드나 — 브라우저 vs 2u 쪽

같은 엑셀 다운로드도 만드는 위치가 두 가지입니다. 손님께 자료를 받을 때 차이를 알아두시면 속도
설명에 도움이 됩니다.

**브라우저 — 6곳** — 단지 비교 / 미분양 단지·지역·실거래·추이 / 미분양
비교 6개 화면은 **브라우저가 직접** 엑셀 파일을 만들어 즉시 다운로드합니다. 2u 쪽을 거치지 않아서
빠르고, 인터넷이 잠시 끊겨도 화면에 떠 있는 자료는 받을 수 있어요. 엑셀을 만드는 부품을
첫 다운로드 때만 받아 두기 때문에 첫 클릭은 1초 정도 느릴 수 있습니다.

**2u 쪽 — 1곳** — 단지 상세의 매물 목록 엑셀은 **2u 쪽에서 만들어 파일로 보내**옵니다.
매물 1000건 이상까지 한 번에 받으려면 브라우저 혼자 감당하기 버거워서 2u 쪽에서
만든 뒤 파일을 보내요. 매물 수가 많은 단지는 30초 정도 걸릴 수 있고, 인증된 손님 계정은
일일 다운로드 한도가 적용됩니다.

두 위치 모두 같은 6글자 계산식 악용 막기가 들어가 있어서 손님 안전 수준은 동일합니다.

## 손님 응대 5분 순서

상담 자료를 손님께 한 번에 떨어뜨리는 흐름은 이렇습니다.

1. **검색·필터** — [단지 검색](/search)에서 손님이 관심 있는 동·아파트명·예산을 잡고 매물을 압축합니다.
2. **+ 비교 추가** — 후보 단지 3~4개에 + 버튼을 눌러 [단지 비교 화면](/compare)으로 보냅니다.
3. **24행 검토** — 단지 비교 화면에서 평당가(3.3㎡당 값)·매매·전세·면적 24행을 손님과 함께 봅니다.
4. **인쇄 1번** — 상단 인쇄 버튼 → A4 한 장으로 즉시 떨어집니다. 종이 손님은 여기서 끝입니다.
5. **엑셀 1번** — 디지털 자료를 원하시면 인쇄 옆 "엑셀 다운로드" 로 같은 비교를 받습니다. 이름은
   `단지비교_2026-05-13.xlsx` 처럼 날짜가 자동으로 들어가서 며칠 후 손님이 다시 열어도 헷갈리지
   않아요.

매물 표가 더 필요하시면 단지를 한 번 더 클릭해서 매물 목록의 엑셀 버튼을 누르시면 28칸
매물 자료가 떨어집니다. 미분양 손님은 같은 흐름을 [미분양 화면](/mibunyang)에서 반복하시면 돼요.

## 한계·주의사항

좋은 도구도 한계가 있어요. 손님께 자료를 약속하기 전에 알아두면 좋은 점 5가지입니다.

- **첫 클릭 1초 느림 (브라우저 6곳)** — 엑셀을 만드는 부품을 처음 받아 올 때 1초 정도 걸려요.
  같은 화면에서 두 번째 다운로드부터는 즉시 떨어집니다.
- **매물 엑셀 일일 한도 (2u 쪽 1곳)** — 인증된 손님 계정은 매물 엑셀 다운로드에 일일 한도가
  적용됩니다. 한도 초과 시 다음날 자동 복구.
- **인쇄는 단지 비교 화면 한 곳만** — 다른 화면 인쇄는 Ctrl+P 가능하지만 줄이 흐트러질 수 있어
  손님 자료로는 비추천. 종이 자료는 비교 페이지에서 떨어뜨리시는 게 깔끔합니다.
- **파일명 한글** — 단지명에 특수 기호가 있으면 운영체제에 따라 다운로드 폴더에서 깨져 보일
  수 있어요. 매물 엑셀은 2u 쪽에서 한글·숫자·점·하이픈만 남기고 나머지를 `_` 로 자동 변환합니다.
- **시크릿 모드에서는 로그인이 따로** — 시크릿 브라우저에서 매물 엑셀을 받으시려면 손님이 다시 로그인하셔야
  합니다. 일반 모드는 [공인중개사 인증](/blog/agent-verification-guide) 후 자동 유지됩니다.
