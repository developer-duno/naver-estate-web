## 미분양 = 위험 신호일까, 기회 신호일까?

손님 앞에서 가장 답하기 까다로운 질문 중 하나가 **"이 단지 미분양이라던데, 사도 돼요?"** 입니다.
미분양은 단순히 "안 팔린 단지" 가 아닙니다. **분양가 자체가 시장 가격보다 비쌌거나**, **입지가
실거주 수요와 맞지 않거나**, **분양 시점이 시장 침체기** 였거나 — 이유는 단지마다 다릅니다.

미분양 단지가 정말 가치 없는지 판단하려면, **분양가·할인율·세대수·용적률·주변 시세** 같은
정량 지표를 한 줄에 놓고 비교해야 합니다. 이 사이트는 이걸 위해 **13축 레이더 + 19행 비교
표** 를 만들었습니다.

## 미분양 메인 화면 5탭

[/mibunyang](/mibunyang) 진입 시 5개 탭으로 정보가 정리됩니다.

| 탭 | 내용 |
|---|---|
| **단지** | 전국 미분양 아파트 목록 (정렬 7종 + 키워드 검색) |
| **미분양** | 단지별 미분양 추이 시계열 |
| **지역** | 시도/시군구별 미분양 통계 |
| **실거래** | 미분양 단지 인근 실거래 흐름 (정렬 5종) |
| **즐겨찾기** | localStorage 기반, 최대 200개 저장 |

상단의 **시도→시군구 2단계 셀렉터** + 키워드 검색을 조합해 후보 지역을 빠르게 좁힐 수
있습니다. URL에 지역·정렬·페이지가 모두 박혀서 손님께 링크 한 줄로 공유 가능합니다.

## 정렬 7종을 손님 의도에 맞춰 쓰기

미분양 목록 정렬은 7가지가 있고, 손님이 어떤 시각으로 보시는지에 따라 다르게 쓰입니다.

- **단지명순** — 단순 사전순. 특정 단지 찾을 때
- **미분양 많은순 / 적은순** — 절대 미분양 호수 기준
- **미분양률 높은순** — 분양 세대 대비 비율. 분양 규모가 다른 단지를 공정 비교
- **세대수순** — 단지 규모. 대단지/소단지 구분
- **분양가 낮은순 / 높은순** — 가격대 후보 좁히기

손님이 "싼 미분양" 을 찾으시면 **분양가 낮은순** 으로, "남아있는 매물 많은 곳" 을 찾으시면
**미분양 많은순** 으로 정렬하시면 됩니다.

## 13축 정량 비교 — 단지 한눈에

비교 페이지([/mibunyang/compare](/mibunyang/compare))에서 단지 2~4개를 고르시면 **13축
레이더 차트** 가 자동으로 그려집니다. 기본 9축 + 인프라 4축은:

| 축 | 의미 | 좋은 방향 |
|---|---|---|
| **세대수** | 단지 규모 | 클수록 |
| **세대당 주차** | 세대당 주차대수 | 높을수록 |
| **최고층** | 최고층수 | 높을수록 |
| **전세가율** | 전세가 / 매매가 | 높을수록(임대 수요) |
| **주변시세** | 인근 단지 매매 중간값 | 높을수록(주변 가치) |
| **할인율** | 분양가 대비 할인 폭 | 높을수록(매수자 유리) |
| **미분양률** | 미분양/분양 세대 비율 | **낮을수록** (invert) |
| **평당가** | 분양가 / 평수 | **낮을수록** (invert) |
| **용적률** | 부지 활용도 | **낮을수록** (invert, 쾌적함) |
| **대기질** | 에어코리아 등급 (좋음/보통/나쁨/매우나쁨) | 좋음 우선 |
| **의료인프라** | 응급의료기관 수 | 많을수록 |
| **보육** | 어린이집 수 | 많을수록 |
| **치안** | 경찰청 범죄점수 | 높을수록 |

invert 표시된 3축(미분양률·평당가·용적률)은 **숫자가 낮을수록 차트에서 멀리 뻗어** 시각적으로
"좋은 단지" 모양이 한눈에 들어오게 설계됐습니다. 인프라 4축(대기질·의료인프라·보육·치안)은
선택 활성으로 손님 거주 환경 중시 시 추가하면 됩니다.

## 가중치 프리셋 3종 — 손님 성향별 줄 세우기

레이더 아래 **가중치 슬라이더(1-5)** 를 펼치시면 축마다 중요도를 조절할 수 있고, 미리 만들어둔
프리셋 3종이 있습니다.

- **균등(모두 3)** — 모든 축 동일 가중치. 객관 비교
- **투자형** — 전세가율 5, 주변시세 5, 할인율 5. 임대 수익·시세차익 관점
- **실거주형** — 주차 5, 세대수 4, 용적률 4. 거주 쾌적성 관점

가중치를 조절하면 차트 아래에 **"★ 종합 우위: ○○ 단지 (78점)"** 형태로 가중 평균 점수가
나옵니다. 손님 앞에서 "이 손님 성향이면 이 단지가 가장 좋습니다" 라고 한 줄로 답할 수 있습니다.

가중치 프리셋·슬라이더·종합 우위 산식 자세한 활용법은 [미분양 레이더 가중치 활용법](/blog/mibunyang-radar-weights) 글에서.

## 즐겨찾기 + 일괄 비교 — 상담 워크플로

긴 상담을 여러 회차에 걸쳐 진행하실 때 **즐겨찾기(★)** 가 가장 빠른 도구입니다.

1. **단지 탭 / 즐겨찾기 탭** 에서 후보 단지에 ★ 표시 — 최대 200개까지 저장
2. **즐겨찾기 정렬** 드롭다운: 추가일순↓ / 단지명순 / 지역순
3. 후보가 모이면 즐겨찾기 탭의 **체크박스로 4개까지 선택** → "선택 비교" 버튼
4. 자동으로 [/mibunyang/compare?ids=...](/mibunyang/compare) 로 이동, 19행 비교 + 차트 3종
5. 비교 결과가 마음에 들면 **"☆ 저장"** 으로 북마크 (최대 20개, 이름 지정 가능)

다음 상담 때 **저장된 비교** 를 다시 누르시면 같은 단지 4개가 즉시 비교 화면에 떠서
"지난번 보여드렸던 그 비교입니다" 라고 이어가실 수 있습니다.

## 미분양 추이 차트 — 분양 흐름의 전환점 잡기

비교 페이지의 **MbCompareUnsoldChart** 는 단지별 미분양 시계열을 한 차트에 그립니다.
기간 필터 6M / 1Y / 2Y / 전체 4단계.

- **계속 줄어드는 단지** — 분양이 정상적으로 소진 중. 늦게라도 들어가면 따라잡을 가능성
- **정체인 단지** — 1년째 같은 미분양 호수. 분양가 조정 없으면 답 없음
- **늘어나는 단지** — 입주 시점이 다가오면서 매도 매물 증가. 잔여 호수 + 입주 매물 합산
- **갑자기 줄어든 단지** — 시행사 할인 분양 또는 단체 매수 가능성. 추가 검증 필요

손님께 "이 단지는 미분양이 줄어드는 중이라 곧 정상 가격으로 회복합니다" 같은 안내를 차트
근거와 함께 드릴 수 있습니다.

## 실무 함정 3가지

1. **차수 접미사 함정** — "○○푸르지오(3차)" 와 "○○푸르지오(2차)" 는 같은 단지가 아닙니다.
   사이트 내부에서 자동으로 마지막 차수만 표시하지만, 손님이 "전체 차수 합쳐서" 라고
   하시면 단지명 검색으로 모든 차수를 모아서 봐야 합니다.
2. **분양가 vs 매물 호가** — 미분양 단지의 분양가는 시행사 표준가이고, 입주 후 매물 호가는
   별개입니다. 단지 상세에서 매물 표를 함께 보세요.
3. **세종·신도시 좌표 함정** — 신축 단지는 도로명주소가 최근 정비된 경우 좌표가 비어 있을
   수 있습니다. 지도가 안 뜨면 단지명 키워드 검색으로 보완.
